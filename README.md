AHK调用libmpv-2.dll的简单播放器

需要AHK2.0 需要MPV的libmpv-2.dll放入AHK文件同目录,或者自定义libmpv-2.dll位置

以下是该脚本的功能说明：

打开程序后可以双击或者拖动文件进行播放.极简,诶呀任何ui界面, 进度和音量在标题栏显示


【键盘控制】

- 空格键：切换暂停或播放状态。

- 方向左键：视频后退 5 秒。

- 方向右键：视频前进 5 秒。

- 方向上键：音量增加 5%。

- 方向下键：音量减少 5%。

- ESC 键：关闭并执行退出清理程序。

- 回车键：切换全屏与窗口模式。

- 小键盘回车键：切换全屏与窗口模式。



【鼠标控制】

- 鼠标中键：切换视频缩放比例。

- 滚轮上滑：音量增加 5%。

- 滚轮下滑：音量减少 5%。

- 鼠标侧前键：视频前进 5 秒。

- 鼠标侧后键：视频后退 5 秒。

- 鼠标右键：切换暂停或播放状态。

- 鼠标左键双击：双击切换全屏与窗口模式。
